# Smoll

Сжиматель и конвертер файлов для macOS. Окно-таблица: перетащил файлы — они сжались
и заменили оригиналы (оригиналы уезжают в Корзину). Плюс пункты в контекстном меню
Финдера: **Make smoll** (jpg/png/pdf/mp4/mov) и **Convert to PDF** (doc/docx/rtf/ppt/pptx).

## Архитектура

Нативное приложение SwiftUI, собирается SwiftPM без Xcode (`./build.sh install`).
Видео и HEIF делает сама macOS (AVFoundation, ImageIO); картинки — инструменты, вшитые в
`Smoll.app/Contents/Helpers`; PDF и Office — Ghostscript и LibreOffice, которые ставятся по запросу
через Homebrew (они тяжёлые: ~50 и ~700 МБ). На чистом Mac без Homebrew из коробки работают
jpg, png, heif, webp, mp4, mov.

| Формат | Чем обрабатывается | Заметки |
|---|---|---|
| jpg | mozjpeg (`djpeg \| cjpeg`), вшит | EXIF/GPS и ICC-профиль (Display P3) сохраняются. Вне бандла (dev-CLI) ищется в keg `/opt/homebrew/opt/mozjpeg/bin`, потом `cjpeg` из bin (обычно libjpeg-turbo), потом ImageIO |
| png | pngquant, вшит | «no gain» (exit 98/99) → оригинал не трогается |
| pdf | Ghostscript `/printer` + принудительная пережимка JPEG | dpi по уровню: 300/220/160/120 |
| mp4, mov | AVFoundation, аппаратный HEVC (VideoToolbox) | `AVVideoQualityKey` по уровню: 0.65/0.55/0.45/0.33 (только Apple Silicon). AAC ≤ 192 kbps копируется без перекодирования, остальное → AAC 80 kbps/канал; HDR (HLG/PQ, 10 бит) сохраняется; поворот, дата съёмки и прочие метаданные контейнера сохраняются |
| doc, docx, rtf, ppt, pptx → pdf | LibreOffice headless | уникальный профиль → работает при открытом LO |
| → HEIF | ImageIO (аппаратно) | конвертация изображений по настройке Format |
| → WEBP | cwebp, вшит | ImageIO WebP только читает, писать не умеет |

Файлы:
- `Sources/smoll/Compressor.swift` — движок: форматы, уровни качества, ресайз, метаданные, замена файла.
- `Sources/smoll/VideoEncoder.swift` — видео через AVAssetReader → AVAssetWriter.
- `Sources/smoll/JobContext.swift` — всё, чем владеет одна задача: временная папка на томе файла,
  её внешние процессы (запуск без блокировки потоков, отмена), ссылка на оригинал с проверкой идентичности.
- `Sources/smoll/Settings.swift` — снимок настроек; читается один раз на старте задачи.
- `Sources/smoll/JobStore.swift` — очередь задач, установка инструментов, кнопка re-run.
- `Sources/smoll/ContentView.swift` — таблица, drag&drop, Quick Look.
- `Sources/smoll/SettingsView.swift` — настройки.
- `Sources/smoll/Main.swift` — вход, CLI-режим, сервисы Финдера.
- `Tests/smollTests/` — XCTest (`swift test`): замена/копия оригинала, настройки, отмена и процессы,
  очередь (через подставные work/install), метаданные JPEG/HEIF, видео (размер, поворот, HDR, звук,
  дата), поиск инструментов. Видеотесты делают сэмплы через ffmpeg и пропускаются, если его нет —
  самому приложению ffmpeg не нужен.
- `app/Info.plist` — сервисы (NSServices), типы файлов, иконка.
- `scripts/vendor-tools.sh` → `app/Helpers` + `app/Licenses`: берёт mozjpeg, pngquant, cwebp из Homebrew
  вместе со всеми их dylib, переписывает пути загрузки на `@loader_path`, подписывает, проверяет, что
  ничего не ссылается в Homebrew, и собирает лицензии + `NOTICE.txt` с адресами исходников
  (pngquant — GPL-3.0: запускается отдельной программой, исходники по ссылке). Запускать заново
  после `brew upgrade`; нужны `brew install mozjpeg pngquant webp`. ~4 МБ.
- `build.sh` — сборка бандла в `dist/` (вшивает `app/Helpers`, `app/Licenses`; если Helpers ещё нет —
  сам запускает vendor-tools.sh); `build.sh install` собирает во временной папке и кладёт
  приложение только в /Applications (копии в проекте не остаётся) и регистрирует сервисы.

## Настройки (⌘, или шестерёнка)

- **Size**: Original / Max width / Max height + пиксели. Действует на картинки и видео.
- **Format**: Original / HEIF / JPEG / PNG / WEBP. Только для картинок.
- **Compression**: один ползунок Normal / Medium / Strong / Extreme (по умолчанию Medium).
  Под ползунком подпись выбранной степени: качество в % (JPEG quality из таблицы `Quality`),
  dpi для PDF и словесное описание потерь.
- **Replace original file** (по умолчанию вкл): выкл → оригинал не трогается, результат
  кладётся рядом как «name smoll.ext» (занято → «name smoll 2.ext»). Re-run в этом режиме
  заменяет предыдущую «smoll»-копию на месте и берёт исходник по его прежнему пути.

После изменения настроек в тайтл-баре появляется ⟳ — прогоняет файлы из таблицы заново.
Прогон честный: программа помнит, куда в Корзине лёг оригинал, и жмёт заново именно его,
так что качество не деградирует каскадом. Предыдущая сжатая версия тоже уезжает в Корзину.
При повторном прогоне результат ставится принудительно, даже если он больше прежнего —
более слабое сжатие означает осознанный выбор качества. Если оригинал из Корзины удалён
(или Корзина очищена), fallback — пережимается текущий файл, как раньше.

## Правила безопасности

- Оригинал всегда уходит в Корзину, не удаляется.
- Результат сначала целиком готовится во временной папке на том же томе, что и файл; оригинал
  трогается только когда результат точно есть, а финальный перенос — мгновенный rename.
- Отменённая задача (Delete на строке, выход из приложения) файл не трогает: проверка отмены стоит
  прямо перед заменой. Временные файлы задачи удаляются при любом исходе.
- Re-run берёт оригинал из Корзины, только если это тот же файл (сверяется file ID): после очистки
  Корзины там может лежать чужой файл с тем же именем.
- Если результат не меньше оригинала (и формат не менялся) — файл не трогается, ratio «—».
- Конвертация с занятым именем — суффикс «name 2.pdf».
- Фото с EXIF-поворотом: быстрый mozjpeg-путь пропускается, поворот запекается через ImageIO.

## FAQ (вопросы из разработки)

**Как ставятся зависимости, видно ли юзеру?**
Для картинок и видео ставить ничего не нужно. Для PDF и Office: если инструмента нет, строка получает статус «needs X» и сверху
появляется оранжевый баннер с кнопкой «Install via Homebrew» и спиннером на время
установки. После установки застрявшие файлы продолжаются сами. Если установка не удалась
(нет сети и т.п.), баннер пишет «Couldn't install X» и кнопку «Try again» — автоповтора нет.
Прогресса скачивания
brew не видно (только спиннер) — если понадобится, можно стримить вывод brew в баннер.
Ждём реальной жалобы.

**Максимальный размер файла?**
Жёсткого лимита нет. Нужно свободное место на том же диске, где лежит файл, примерно на размер
результата (результат пишется во временную папку этого тома, потом переименовывается на место). Практический потолок — время:
часовое видео кодируется десятки минут (аппаратный HEVC, но всё же).

**Сколько файлов можно закинуть?**
Лимита нет — хоть 500. Таблица ленивая, одновременно работают максимум 3 задачи.

**По очереди или параллельно?**
До 3 задач параллельно (`JobStore.maxParallel`), но видео — строго по одному: два аппаратных
кодирования только дерутся за один энкодер. Внешние процессы ждутся через terminationHandler,
так что долгие задачи не держат потоки.

**Что если файл зависнет?**
Автотаймаута нет — и осознанно: большое видео легально кодируется десятки минут,
машина не отличит «долго» от «зависло». Вместо этого — ручная отмена: Delete (или
«Remove from list» в контекстном меню) на строке в работе убивает её внешние процессы
(и только её — установку brew отмена не задевает), очередь продолжается. Оригинал при отмене
не тронут. Закрытие приложения молча отменяет всё, что в работе, — Ghostscript и LibreOffice не остаются
кодировать в фоне.

**Доступ к папкам.**
macOS спрашивает доступ к Desktop/Documents/Downloads по одному разу на категорию.
Чтобы это не размазывалось по времени, при первом добавленном файле программа трогает
все три папки — все запросы приходят сразу, один раз за жизнь приложения.

## Иконка

Исходник — `smoll-icon-iOS-Default-1024x1024@1x.png` (полнокадровый iOS-вариант).
Для macOS контент уменьшается до 824 px и центрируется на прозрачном холсте 1024
(стандартная сетка macOS: иконка занимает ~80%, поля — под тень). Генерация:
`ffmpeg scale+pad → iconset → iconutil`, результат `app/AppIcon.icns` в репозитории;
пересобирать нужно только при смене исходника.

## Сервисы Финдера

Два сервиса в Info.plist с разными UTI. Кэш сервисов обновляется lsregister'ом из
build.sh; если пункт не появился — перелогин. Смешанное выделение (jpg + docx) не
покажет ни один пункт — macOS требует, чтобы все файлы подходили под один сервис;
для смеси — перетаскивание в окно.

## CLI / самопроверка

`./.build/release/smoll --cli file1 file2…` — тот же движок без UI, печатает
`old -> new (-N%)`. Настройки для CLI-бинарника лежат в домене `smoll`
(`defaults write smoll level -float 3`), у приложения — `ee.timur.smoll`.
Этот бинарник лежит вне бандла и берёт инструменты из Homebrew. Чтобы проверить вшитые —
`dist/Smoll.app/Contents/MacOS/Smoll --cli …` (настройки тогда из `ee.timur.smoll`). Mac без Homebrew
можно сымитировать: `sandbox-exec -p '(version 1)(allow default)(deny file-read* (subpath "/opt/homebrew"))' …`.
